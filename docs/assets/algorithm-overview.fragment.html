s_raw = [TCP7, q6, opening1]                         # [B,14]
s_local[:7] = [0,0,0,0,0,0,1]                        # 当前 TCP 自身是 identity
q_normalized = (q − center_train) / scale_train
opening_normalized = 2 × opening − 1
s = Linear14→256(s_local_normalized)
c = E_time(τ=1) + s + gate × E_key(key_relative)
Q_k = learned_k + E_tick(kΔt) + E_action(Y_init,k) + c
h_mod = (1 + scale(c)) ⊙ LayerNorm(h) + shift(c)
h_out = h + residual_gate(c) ⊙ Branch(h_mod)

      
各层分别为 self-attention、cross-attention 和 FFN 生成调制参数。当前 TCP 虽在状态投影中固定为 identity，仍参与场景/key 的局部变换和动作的世界坐标恢复；当前没有关节速度、TCP 速度或历史状态。

      
归一化与直接通路减少状态被忽略的机会，回归直接监督部署输出，并沿用位移/二阶差分等物理损失。用户已确认 regression_state 整体解决本次轨迹问题；各项改动的独立贡献仍需消融。

    训练、推理与执行：不要混淆的三个环节
    
O2：GT 是辅助监督，不是预测策略输入

    
预测角色图对照 GT T/R 点投影 prior，结合匹配、objectness 与 NULL 辅助监督；同时学习 key-action。Gaussian teacher 不是严格实例边界。标准 RLBench key-action 训练使用 GT waypoint 及其扰动构造 refine crop，部署使用预测 coarse waypoint，存在需要验收的 teacher-forcing 差异。

    
L_O2 = L_key-action + λ_mask L_mask + λ_presence L_presence + 可选辅助项

    
OHT chunk：训练条件使用预测 key/crop

    
joint 模式另算 GT key-action loss；chunk 条件分支走 prediction-only 路径，GT key 不替换 decoder 输入。key 的离散解码和 crop 不可微；joint 可训练共享视觉特征，但不代表 chunk loss 穿过 key 的 argmax。

    
L_joint = λ_key L_key + L_chunk [+ λ_flow L_flow]
L_chunk = λ_p L_position + λ_R L_rotation + λ_g BCE
        + λ_Δ L_displacement + λ_Δ² L_second-difference

    
位置用物理尺度下 Smooth L1，旋转比较旋转矩阵；二阶差分匹配 GT 的位移变化，不是把所有转弯压平。所有未来标签损失按 m* 屏蔽，不跨缺帧/padding。Flow 的训练重建误差不能替代独立噪声采样的部署误差。

    
滚动执行：一次预测 K，只执行前 Hₑ

    
观测 Oₜ → 预测 Â₁:K → 消费 Â₁:Hₑ → 重新观测 → 再预测
K = 16，Hₑ = 4；物理前缀时长 = Hₑ × Δt

    
Δt 从 V4 时间戳与 frame_stride 解析并绑定契约，不能从 observation sample_stride 猜测。ChunkExecutor 在 tick 间插值位置和旋转，夹爪在对应 tick 边界切换；不等待到达远期 key 后才推进。跟踪误差、关节越限或环境终止可能提前中断，因此并非每次一定执行完 Hₑ 项。

    
当前 HTTP 等待暂停物理；包含网络/推理墙钟开销，不是异步实时系统。原有 waypoint 执行器与 timed chunk 是不同协议。OHT 输出不含有监督的 collision flag，也不等于具备碰撞规划。

  


  

    当前实现边界与配置选择
    
    
      
  • O2 soft-coarse：rlbench_o2_internal_slots_soft_coarse.yaml；两级独立无序 slots，soft_coarse_queries=True，旧动作/context 路由，objectness 阈值 0.25。
    • 
      
  • 旧固定 T/R queries、硬继承与高分辨率 mask head 仍是独立实验；不是 soft-coarse 模式默认执行的模块。打开 shared_action_features 才让 anchor-enhanced feature 同时进入 R/G/C 的 global/local 路由。
    • 
      
  • OHT 当前已获用户轨迹改善确认的基线为 oht_chunk_v4_regression_state_8x40.yaml；不等于已有完整定量闭环结果。delta_state 与 flow_state 需要独立验收。
    • 
      
  • V4 chunk 目前只支持 baseline + EEF。不能在图上把 T/R → anchor → chunk 画成已实现直连；数据中有 object 标注也不会自动启用条件化。
    • 
      
  • regression_state 继承链文件名包含 flow，但最终 decoder_type=regression；较早 oht_chunk_v4_flow_8x40.yaml 不含后续 state/AdaLN/尺度等整套改动。
    • 
      
  • 时序卷积处理一次预测内的 K 个未来动作，并不是历史帧 memory；当前没有持久 object bank、显式 phase 识别或已证明的坍塌恢复能力。
    • 
      
  • 角色身份用于“操作谁”；局部接触、方向和间隙的增强属于待验证设计，不能把当前 anchor 响应解释成经过监督的接触点。
